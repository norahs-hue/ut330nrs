Interaction Field Study

September 21, 2026 · Week 4

For this assigniment, we were asked to create a field report on an interaction that was flawed. I chose to focus on the package pickup kiosk in my apartment building, which has caused my roomates and I frustration in the past. The field report needed evidence, an experince map, and observations. I was able to create a journey map because of the process being linear. I used Google Slides to create the report, starting with context and a problem statement, "Package will be delivered by a delivery driver, and the driver sometimes does not check in the package with a code or confirmation, leaving the package sitting in the kiosk for days before an Arbor Blu employee manually checks in the package." And a workaround that my roomates and I currently use, "Sometimes, one of my roommates will have an unused code, and in return for my use of the code I will retrieve their package for them. You cannot enter the package room without an individual code. " While this workaround is valuable, it ignores the systemic interaction design flaws of the kiosk and defeats its original purpose.
I then went through the process of picking up a package from the kiosk from start to finish. I was able to use screenshots of the original messages notifying me to use my code (or barcode) to pick the package up, and complete the interaction from there. I noted that my journey was smooth this time: I recieve my code, go to the kiosk and enter the code, and the door unlocked for me to retrieve my package.
After my journey, I noticed the biggest takeaway: delivery drivers should NOT be required to input the intense amount of information into the kiosk that they are instructed to do. This includes scanning the package, inputting the recipient's name and apartment number, typing in a personal code from the leasing office, and repeating this process per package. This amount of work is time consuming for the driver who is on a tight schedule already, and there should be enough information for the recipient to pick up their package by the driver scanning that package only. Or, there could be a system, similar to an amazon locker, that completes this process after the packages are dropped off (a leasing office employee would have to handle the scanning portion). Otherwise, I believe that the kiosk could be re- designed in a way that is more user friendly and efficient for all parties involved.
