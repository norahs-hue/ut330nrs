For this assigniment, we were asked to create a field report on an interaction that was flawed. I chose to focus on the package pickup kiosk in my apartment building, which has caused my roomates and I frustration in the past. The field report needed evidence, an experince map, and observations. I was able to create a journey map because of the process being linear. I used Google Slides to create the report, starting with context and a problem statement, "Package will be delivered by a delivery driver, and the driver sometimes does not check in the package with a code or confirmation, leaving the package sitting in the kiosk for days before an Arbor Blu employee manually checks in the package." And a workaround that my roomates and I currently use, "Sometimes, one of my roommates will have an unused code, and in return for my use of the code I will retrieve their package for them. You cannot enter the package room without an individual code. " While this workaround is valuable, it ignores the systemic interaction design flaws of the kiosk and defeats its original purpose.
